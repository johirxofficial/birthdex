Verify a birth or death registration.

Enter the 17-digit registration number and the date. BirthDex shows the BDRIS portal captcha — type what you see and the record comes back. No OCR, no automation of the captcha.

Manual captcha Open source Self-hosted No data stored

Step 1 · Registration details

Record type

17 digits, as printed on the certificate (UBRN or UDRN).

The date shown on the certificate.

Step 2 · Type the captcha

Usually a short sum such as 45+12=? — type the result. Case does not matter.

Record

Verified

How it works

  1. 1

    Send the number and date

    BirthDex opens a session on the public BDRIS e-Verify portal.

  2. 2

    Read the captcha

    The portal captcha is shown to you. Solving it is always manual.

  3. 3

    Get the record

    The response is a clean JSON record — or a new captcha to retry.

API

Try it 
GET /api/verify?type=birth&number=19901234567890123&dob=1990-01-01
# → 428 + captcha { id, image_url }

GET /api/verify?type=birth&number=19901234567890123&dob=1990-01-01&captcha_id=...&captcha=56
