# Code of Conduct

## Our pledge

We want BirthDex to be a welcoming project for everyone, regardless of
experience level, language, nationality, gender, religion or background.

## Expected behaviour

- Be respectful and assume good faith.
- Give actionable, kind feedback on code and ideas.
- Respect privacy: never share real citizens' records, registration numbers or
  screenshots that contain personal data.
- Respect the upstream service: no scraping, flooding or captcha bypass.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Publishing others' private information without permission.
- Using the project or its issue tracker to obtain or distribute personal data
  unlawfully.
- Attempts to turn the project into an automated captcha-solving or bulk
  scraping service.

## Scope

This code applies to issues, pull requests, discussions and any other project
space, and to interactions made on behalf of the project elsewhere.

## Enforcement

Maintainers may edit or remove comments, close issues and block contributors
who violate this code. Report problems to the maintainers listed in the
repository profile. Reports are handled confidentially.
